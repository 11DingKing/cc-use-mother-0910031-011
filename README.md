# 违规线索分流处置

市级监管部门集中受理**投诉、巡查、机构自报**三类违规线索的分流处置服务端。解决同一事件多渠道重复登记、严重线索在普通队列延误、多人重复处置、敏感证据越权可见等问题。

- 仅依赖 Python ≥ 3.11 标准库（SQLite + `http.server`），零第三方依赖。
- 领域词汇与 `domain/contract.json` 对齐：五状态（登记 → 待核验 → 处置中 → 已决定 → 已归档）与四个关键不变量（多源线索去重、风险优先级版本、租约并发认领、敏感证据裁剪）。

## 能力一览

| 需求 | 实现 |
| --- | --- |
| 来源指纹 | 渠道 + 文号 + 主体证件 + 发生日期 + 标题规范化哈希；同指纹登记幂等返回 |
| 涉及主体 | 机构/人员主体库，统一社会信用代码/证件号去重锚点 |
| 敏感证据 | 普通/内部/敏感/机密四级，按角色上限裁剪，超范围只保留存在性与分级 |
| 风险规则 | 版本化、不可变；受限 JSON 条件确定性求值；支持按新版本重评分 |
| 办理时限 | 优先级默认时限（特急24h … 低240h），延期需申请—批准并累计留痕 |
| 合并建议 | 同主体标题相似度 + 同日 + 文号一致等加权打分，**只建议，授权人员确认** |
| 优先级建议 | 系统给建议分与建议级，**人工确认**后才生效并起算时限 |
| 租约认领 | 限时租约 + `BEGIN IMMEDIATE` 行锁，并发下只有一人认领成功，可续租/释放/转派 |
| 状态约束 | 受理/核验/结案/归档/复开/合并/拆分均校验来源状态，非法迁移返回 409 |
| 临时措施 | 处置中可采取/解除；生效措施未解除、延期待审批时禁止结案 |
| 审计轨迹 | 每个分流动作追加记录操作人、角色、前后状态、理由与明细，不可改写 |

## 角色

契约角色：机构合规员、执业人员、监管人员、复核专家；另设运行期调度角色 **分流管理员**（授权确认合并/优先级、转派、规则发布、账号管理）。

| 角色 | 典型权限 | 证据可见上限 |
| --- | --- | --- |
| 机构合规员 | 登记线索、补普通证据、查看 | 普通 |
| 执业人员 | 查看（本人相关） | 普通 |
| 监管人员 | 登记、确认合并/优先级、认领核验、分派转派、措施、延期审批、结案 | 敏感 |
| 复核专家 | 认领核验、复核、措施、延期申请、拆分 | 机密 |
| 分流管理员 | 全部处置动作 + 发布规则 + 账号管理 | 机密 |

## 典型分流流程

```
投诉/巡查/自报登记（自动指纹、评分、合并建议）
   │  登记
   ├─ 授权人员确认合并建议（重复件并入主件并归档；或驳回）
   ├─ 授权人员确认优先级 + 办理时限 ──► 待核验
   │
   ├─ 认领（租约）→ 核验通过 ──► 处置中
   │      ├─ 转派（须填理由，租约移交）/ 释放 / 续租
   │      ├─ 拆分（母线索保留，子线索进入待核验）
   │      ├─ 临时措施（结案前须解除）
   │      └─ 延期申请 → 审批（时限顺延并留痕）
   ├─ 结案（决定类型 + 摘要）──► 已决定
   └─ 归档 ──► 已归档（仅未合并件可复开回处置中）
```

完整接口清单见 [docs/api.md](docs/api.md)。

## 关键设计

- **来源指纹**：`sha256(渠道|文号|主体证件大写|发生日期|标题去标点小写前80字)`。完全一致按重复登记幂等处理；不一致但同主体时用标题二元组 Jaccard、同日(+0.6)、文号一致(+0.4)、同辖区(+0.1)、同渠道(+0.05) 加权，≥0.45 生成合并建议。
- **人工确认原则**：合并与优先级都落 `待确认`/建议字段，仅 `分流管理员/监管人员` 确认后生效；系统动作不替人作决定。
- **租约**：`leases` 单行 `clue_id PRIMARY KEY`，过期判断在事务内即时清理；写事务统一 `BEGIN IMMEDIATE`，并发认领在 SQLite 写锁下串行化，保证只有一张 200（见 `tests/test_api.py::ConcurrentClaimTest`，12 并发仅 1 成功；同指纹 8 并发登记只产生 1 条线索）。
- **证据裁剪**：服务端按角色敏感度上限序列化，越权证据不返回 `label/content_ref`，仅返回分级与 `redacted=true`；人员证件号、举报人联系方式对机构端打码。
- **审计**：`audit_logs` 只追加；每次分流返回的理由同时入库，线索详情内嵌完整审计轨迹。

## 目录

- `domain/contract.json`：领域角色、状态、不变量与样例。
- `src/domain_contract/`：契约读取与确定性校验。
- `src/violation_triage/`：
  - `config.py` 角色/权限/敏感度/时限配置；`risk.py` 版本化规则引擎；
  - `database.py` SQLite 结构；`service.py` 领域服务（状态机、租约、合并、审计）；
  - `api.py` HTTP 路由与认证；`app.py` 启动与种子数据；`security.py` PBKDF2 哈希与令牌。
- `tests/`：契约、规则引擎、领域服务（59 项）与真实 HTTP/并发回归。
- `tools/check_contract.py`：契约命令行摘要。
